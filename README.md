# Wilton-Jess Mobile Auto Repair

Website for Wilton-Jess Mobile Auto Repair, a mobile mechanic serving Riverside, CA and the area within 30 miles.

Live site: https://sandraboyoaruleba.github.io/wilton-jess/

## Updating the site
Everything is in `index.html`. The values to edit are near the top of the `<script>` section, under "EDIT HERE":

- `WA_NUMBER` / `WA_DISPLAY`: the WhatsApp number (digits with country code, e.g. `19515551234`)
- `SERVICES`: the repairs and prices
- `TESTIMONIALS`: customer reviews (set `placeholder: false` on real ones)
- `CITIES`: the service area

Changes go live a minute or two after they're committed to `main`.
